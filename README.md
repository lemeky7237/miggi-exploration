# 미끼탐험모드 (Miggi Exploration)

Fabric 모드 · Minecraft 26.3

- **탐험 일지** (J 키, 또는 책+나침반으로 만드는 `탐험 일지` 아이템): 발견한 장소 목록과 도전과제·칭호
- **새로운 장소 발견** 두루마리: 처음 가 보는 지역에 들어가면 화면 위에 표시
- **도전과제 15개**: 달성하면 칭호를 얻음
- **탐험 보물 7종**: 고대 금화, 진주 조개, 하늘 수정, 심연 수정, 벚꽃 부적, 정령의 잎, 빛버섯 — 구조물 상자에서 발견

## 받는 법
`main`에 푸시하면 GitHub Actions가 빌드하고 서버 부팅 검사까지 한 뒤, 완성된 jar를 `jar` 브랜치에 올림.

텍스처는 `tools/make_art.py`로 생성함.
